# DeepDRRとDiffDRRの位置一致性に関する重要な問題

## 背景
gpt5pro1.mdとgpt5pro2.mdの実装方針に基づいてマスク投影機能を実装したが、DeepDRRとDiffDRRの位置一致性に関する重大な問題が判明しました。

## 実装内容とその結果

### 1. 実装した内容
- **LPS正規化**: nibabelによるCTとマスクの厳密なLPS正規化を実装
- **DiffDRR投影**: `diffdrr.data.read`でマスクファイルを読み込み、Siddon線積分で投影
- **基本設定**: 
  - orientation="PA"
  - center_volume=True
  - pose_angles = [0., 0., 0.]（正面投影）
  - translation = [0., 0., 0.]（原点中心）

### 2. 実際の観察結果

#### マスクデータ詳細:
```
- 形状: (1024, 1024, 251)
- ボクセルスペーシング: (0.341796875, 0.341796875, 1.5) mm
- 非ゼロボクセル数: 796,876 / 263,192,576 (0.303%)
- マスクの実際の重心（物理座標）: [-38.65, -128.88, 181.23] mm
```

#### 投影テスト結果:
1. **マスク重心を平行移動に使用**: 厚み = 0.000 mm（投影失敗）
2. **原点中心（[0,0,0]）を平行移動に使用**: 厚み = 18.23 mm（投影成功）

### 3. **重要な発見：座標系の不一致**

gpt5pro1.mdでは以下のように記載されています：
> **3. DiffDRR に DeepDRR の姿勢を渡す**  
> 公式チュートリアルの写像に従い、DeepDRR の **(α,β,γ)** を DiffDRR の Euler に変換：  
> **αᴅʀʀ = α, βᴅʀʀ = 90° − β, γᴅʀʀ = −γ**

> **5. PA だけ左右反転している既存パイプラインに合わせる**  
> あなたの最終版は「PA のみ最終水平反転（`img_pa[:, ::-1]`）」で仕上げています。**マスク側にも全く同じ後処理**をかければ、**ピクセル単位で完全一致**します。

しかし実装において以下の問題が発生：

### 4. 具体的な問題点

#### A. 座標原点の不一致
- **理論上**: DeepDRRとDiffDRRは同じ幾何学設定で完全一致するはず
- **実際**: マスクの物理的重心（[-38.65, -128.88, 181.23] mm）で投影すると失敗
- **成功条件**: 原点中心（[0, 0, 0]）でのみ投影成功

#### B. LPS正規化後の座標系問題
DiffDRR `diffdrr.data.read`の内部処理：
```python
subject = read(
    volume=str(mask_path),
    orientation="PA", 
    center_volume=True  # これによりマスクが原点中心化される
)
```

この処理により：
1. マスクが自動的に原点中心に移動される
2. 元のCTの物理座標系との対応が失われる
3. DeepDRRで使用するisocenter位置との不整合が発生

#### C. 角度変換の未検証
- gpt5pro1.mdの角度変換式（αᴅʀʀ = α, βᴅʀʀ = 90° − β, γᴅʀʀ = −γ）を実装していない
- 現在は両方とも [0., 0., 0.] の正面投影のみテスト
- PA投影での左右反転処理も未実装

## 質問

### 1. 座標原点の一致性について
gpt5pro1.mdでは「**ピクセル単位で完全一致**」と記載されていますが、実際にはDiffDRRの`center_volume=True`によりマスクが原点中心化され、DeepDRRで使用する`isocenter_in_world`位置との不整合が生じています。

**どのようにしてDeepDRRのisocenter位置とDiffDRRの中心化されたマスク位置を一致させればよいでしょうか？**

### 2. 角度変換の具体的実装について
現在の実装では角度変換を適用していませんが、gpt5pro1.mdの変換式：
- αᴅʀʀ = α
- βᴅʀʀ = 90° − β  
- γᴅʀʀ = −γ

この変換式を適用する際、DeepDRRの`MobileCArm`から取得すべき角度パラメータと、DiffDRRの`forward()`に渡すべき具体的な角度値を教えてください。

### 3. 検出器パラメータの完全一致について
現在の実装：
```python
# DeepDRR
carm = MobileCArm(
    source_to_detector_distance=1800,
    pixel_size=1.4,  # テスト用
    sensor_width=256, sensor_height=256  # テスト用
)

# DiffDRR  
drr = DRR(
    sdd=1800.0,
    delx=1.4, dely=1.4,
    width=256, height=256
)
```

DeepDRRの`Projector`から取得すべき正確なパラメータと、DiffDRRへの正しい変換方法を教えてください。

### 4. PA投影の左右反転処理について
gpt5pro1.mdでは「PA のみ最終水平反転（`img_pa[:, ::-1]`）」と記載されていますが、この処理をDiffDRRでも適用する際の正確なタイミングと方法を教えてください。

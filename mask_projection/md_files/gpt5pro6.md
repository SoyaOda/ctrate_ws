了解です。すでに**位置は完全一致**していますので、ここからは**画素値（強度）を“線積分厚み”に一致**させるための二つの実装プランを、目的・数式・実装ステップ・検証方法まで落として提示します。

下の **Plan‑A は「単色（実効）モデル」**、\*\*Plan‑B は「多色（実スペクトル）＋ビームハードニング補正」\*\*です。どちらも **I/I₀ 正規化 → −log → 厚み**の流れを基軸にします（Beer–Lambert）。単色なら **I/I₀ = exp(−μ·L)** なので **L = −log(I/I₀)/μ** が厳密に成り立ちます ([onlinelibrary.fully3d.org][1])。一方、診断 X 線の現実は多色で **I = ∫S(E)·exp(−∫μ(E)dl) dE**、ここから −log(I/I₀) は L に線形でなく、**ビームハードニング**が生じます（高エネルギー優勢化による非線形） ([ndt.net][2])。

## Plan‑A（推奨：まずはこれで“厚み＝mm”を厳密化）

**単色（実効）モデル**で **画素値 ∝ 厚み**を保証。DeepDRR のパイプラインは踏襲しつつ、**I/I₀ 正規化 → −log → μ\_eff によるスケール合わせ**で **∑L·A = 3D 体積**を一致させます（A は画素面積）。実質的に\*\*水等価長（WEPL）\*\*に相当する厚み画像になります。

### 数式と狙い

* **単色**なら： $ \frac{I}{I_0} = e^{-\mu L}$ → $L = -\log(I/I_0)/\mu$。
* **実機は多色**だが、**実効係数 μ\_eff を自己較正**（体積一致）で定めれば、**画素ごと L が mm スケールで一貫**し、**∑L·A = V\_{mask,3D}** を満たす（計測的に一番ズレにくい）。
* 物理的 μ は材料・エネルギに依存しますが（例：NIST XCOM の質量減弱係数） 、ここでは\*\*“厚みの定義”を優先\*\*し、**μ\_eff は幾何的なスケール係数**として決めます。

### 具体的変更点（あなたの `mask_deepdrr_projection.py` に対する差分）

1. **Flat‑field（I₀）を同解像度で取得**
   既に実装済みの `make_air_volume_like(vol)` を使用して、**同じ幾何・同じ反転規則**で `I_air` を投影。
2. **I/I₀ → −log**
   `ratio = clip(I_mask/I_air)`、`G = −log(ratio)` を実装（済）。
3. **実効 μ の自己較正（体積一致）**

   * 既存 `thickness_from_energy()` の **μ\_eff = (A·∑G) / V\_3D** は正しいです。
   * ここで A = $p^2$（ピクセルピッチ $p$ の二乗）。
   * **薄い外縁のノイズ**は `support_tau`（G の閾値）でシルエットを切る。
4. **厚み画像**

   * `T_mm[Ω] = G[Ω]/μ_eff`、Ωはシルエット。**この T\_mm が“mmの厚み”**。
   * 最後に **PA の水平反転を一度だけ**（あなたの規則どおり）。
5. **検証**

   * **体積一致**：(|∑T·A − V\_{3D}| / V\_{3D} < 1〜2%\*\*（あなたのログでは **0.00%** で良好）。
   * **境界の線状化**：中央行/列の勾配最大値・位置をレポート。
   * **差分 QC**：Siddon 厚み（後述）との L2/MAE を optional で出す。

> 💡 **そのまま運用 OK**：あなたの最新版はこの Plan‑A を **既に実装して成功（体積誤差 0%）** しています。あとは**関数を分離**して（下記）使い回せるようにすると堅牢です。

## Plan‑B（ビームハードニング補正：多項式マッピングを同定）

**多色スペクトル由来の非線形**を、**−log(I/I₀) → 厚み（mm）**の**多項式（または LUT）**で**画素ごとに補正**します。**教師は Siddon 厚み L\_true**（μ=1 の幾何線長）を使うのが安定。「材料が1種類（脂肪）」ならこの補正は滑らかで低次（2〜3次）で十分です。**既報でも多項式補正が標準的**です ([ndt.net][2])。

### ステップ

1. **データ準備（各ビュー）**

   * すでに構築済みの **I\_mask, I\_air → G = −log(I/I₀)**。
   * **Siddon 厚み L\_true** を同じ幾何で作る（あなたの Siddon 実装を流用）。
   * **学習領域 Ω** はシルエット（G>τ）∩（L\_true>0）。
2. **モデル**

   * **多項式補正**： $L_{\text{true}} \approx a_0 + a_1 G + a_2 G^2 + a_3 G^3$。
   * $a_0$ は 0 近傍だが、オフセットのドリフトを吸収できるように自由に。
   * **ロバスト回帰**（Huber など）で係数 $\{a_k\}$ を推定。
3. **適用**

   * 推定後は**新しい G**から**厚み $ \hat{L}=P(G)$** を即時計算。
   * **負値クリップ**、**最大幾何長でクリップ**。
4. **ビュー／装置条件の扱い**

   * **角度依存は小さい**（幾何は同じ）ので、同一 kVp・同じ散乱条件では**係数を流用**可。
   * **kVp やフィルタが変わる**とスペクトルが変化 → **係数を条件別に保存**。
5. **検証**

   * **体積一致**：$|∑\hat{L}·A − V_{3D}|/V_{3D}$ を閾値 <1〜2% で監視（Plan‑A と同等）。
   * **画素単位誤差**：$\mathrm{MAE}(\hat{L}, L_{\text{true}})$、外縁のオーバー/アンダーをヒートマップで評価。

> 参考：**ビームハードニングは多色ビームの一般的アーティファクト**で、**実験的・多項式補正**が CT/工業 X 線で広く使われています（ステップウェッジで −log(I/I₀) と厚みの関係を合わせ込む） ([ndt.net][2], [ResearchGate][3])。
> （ポリクロマティックな減衰の式そのものは上記の積分形で記述されます。） ([ndt.net][2])

### 実装の最小差分（概念コード）

```python
# 準備：学習データ
G = -np.log(np.clip(I_mask / np.clip(I_air, 1e-6, 1.0), 1e-6, 1.0))
L_true = siddon_thickness_map(...)  # 既存Siddonでmm厚み

Omega = (G > tau) & (L_true > 0)
x = G[Omega].reshape(-1,1)
X = np.hstack([np.ones_like(x), x, x**2, x**3])  # 3次まで

# ロバスト回帰（例：Huber）
coef = robust_fit(X, L_true[Omega])

# 推定
L_hat = np.polyval(coef[::-1], G)  # a0+a1G+a2G^2+a3G^3
L_hat = np.clip(L_hat, 0, L_max_geom)

# 体積一致で最終 1D スケール補正（微調整）
scale = (V_3D / (A * L_hat.sum()))
L_hat *= scale
```

**メリット**

* **局所的な非線形**（厚いところの暗くなりすぎ等）を追従 → **位置ごとの厚みがより忠実**。
* **Plan‑A と同等の体積一致**を維持しつつ、**画素毎誤差**を下げられる。

**限界／注意**

* **教師（Siddon 厚み）が必須**。
* **kVp/フィルタ**が変われば係数も変化（条件別の係数管理が必要）。
* 散乱（被写体散乱/検出器散乱）や**I₀ のずれ**は別途 FFC（フラットフィールド）できれいにする。
  （**I/I₀ 正規化**は X 線画像の前処理の基本）

## 実装時に“必ず”守るべき幾何＋数値の注意点

* **偶数サイズの主点 0.5px 補正**（あなたの実装どおり）。
* **PA 水平反転は最後に 1 回だけ**。
* **I\_air は同一幾何で撮る**（一度キャッシュして再利用）。
* **Ω（シルエット）を適切に選ぶ**：低 G を切らないと薄層周辺のノイズで μ推定が揺れる。
* **厚み→体積の QC**：常に $\sum L \cdot p^2$ と 3D 体積（voxel\_count·dx·dy·dz）を比較。
* **Siddon の厚みは“ボクセル二値”で**（補間なし）：境界の線状化（エッジの鋭さ）を守る。Siddon のレイトレーシングは古典的手法で、**3D 体積配列に対する厳密な線路長**を高速に計算します ([arXiv][4])。

## どう使い分ける？

* **学習用の「厚み」教師**が欲しい：**Plan‑A**（あるいは **Siddon 直算**）で十分。
* **物理的レンダリング（DeepDRR エネルギ）の値から**厚みを**安定変換**したい：**Plan‑B**。

  * まず Plan‑A で体積一致の μ\_eff を入れ、その後 **多項式補正**でピクセル単位誤差を詰める。
* **材料パラメータを物理的に固定**したい場合は、**NIST XCOM**の μ/ρ と密度 ρ を使って**目標エネルギ（実効エネルギ）で μ を算出**し、Plan‑A の μ\_eff を物理値で固定するのも可（ただし多色ビームでは体積一致が崩れる点は理解が必要） 。

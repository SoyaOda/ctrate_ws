# DiffDRR実装：胸部X線らしい画像が生成できない問題

## 環境
- DiffDRR v0.5.1
- TorchIO 0.20.21
- PyTorch 2.8.0
- CUDA 12.0

## 現在の状況

DRR画像は生成されるものの、胸部X線らしい見た目になりません：
1. 横縞模様やブロック状のアーティファクトが表示される
2. 肺野、心臓、肋骨などの解剖学的構造が明瞭に見えない
3. カメラ位置を調整しても改善が限定的

## 試したアプローチと結果

### 1. read()関数の直接使用
```python
subject = read(ct_path, bone_attenuation_multiplier=3.0)
drr = DRR(subject=subject, sdd=1800.0, height=512, width=512, delx=0.7, dely=0.7)
```
結果：縞模様のアーティファクト

### 2. 手動でのLAC変換
```python
volume_lac = (volume_clipped + 1024) * (mu_water / 1000.0)
```
結果：部分的改善はあるが、まだX線らしくない

### 3. 異なるカメラポーズ
- Y=-50: 胸郭の下部のみ表示
- Y=-100: ボリューム全体は見えるが、縞模様
- 回転追加: わずかに改善するが不十分

## 観察されるボリューム情報
```
Volume shape: torch.Size([1, 1024, 1024, 251])
Volume range: [-1024.000, 3071.000]  # HU値のまま？
Image range: [1.166, 1.379]  # 投影後の値が低すぎる
```

## 疑われる原因

1. **軸順序の不一致**: 
   - NIfTI: 通常は(X, Y, Z)または(W, H, D)
   - DiffDRR期待値: (1, H, W, D)？それとも(1, D, H, W)？
   - read()関数の内部変換が不明

2. **座標系の問題**:
   - RAS vs LPS座標系の違い
   - アフィン行列の解釈の違い

3. **密度変換の問題**:
   - read()関数がHU値をそのまま使用している可能性
   - 適切なLAC変換が行われていない
